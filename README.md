This repo's purpose is to collect .gpx traces from community's experienced rollerskating trail practitioners.
It aims at cataloguing and distributing trail roads to roller skaters in Scotland.
This is a volunteer open source project run by and for Glasgow's rollerskating community.
We aim to help other roller skaters practice this wonderful sport and show our local councils it is worth investing into our roads.

Submissions, questions, enquiry, joining, donations all welcome at above email.
